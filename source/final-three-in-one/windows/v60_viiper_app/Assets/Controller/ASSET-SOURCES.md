# Controller visual assets

- `ns2pro-shell.mesh`: original artistic reconstruction, traced from the front
  and rear product reference images supplied by the user. Generated by
  `tools/modeling/generate_ns2pro_shell.py`. Not manufacturing CAD.
- `switch2-official-mark.svg`: unmodified vector source downloaded from
  https://www.nintendo.com/jp/hardware/switch2/assets/img/scene1/welcome-hero-logo.svg
  on 2026-10-16. The runtime uses its original path outlines, with the original
  even-odd fill rule, recoloured charcoal as a mark on the controller model.
  Nintendo Switch and Nintendo Switch 2 are Nintendo trademarks. This asset
  identifies the represented controller and is not the application's logo.
  The same logo's Commons provenance and PD-textlogo classification are recorded
  at https://commons.wikimedia.org/wiki/File:Nintendo_Switch_2_logo.svg .

No paid third-party controller mesh or texture is used.
